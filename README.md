# Nextcloud-Quick-Share

開いている Nextcloud のページからファイルをアップロードし、パスワード付き・期限付きの
公開共有リンクを作成して URL をクリップボードにコピーする Edge / Chrome 拡張機能です。

## 仕組み

ログイン中のセッション（Cookie）と、ページに埋め込まれている `data-requesttoken` をそのまま使うため、URL やアプリパスワードの登録は不要です。

1. WebDAV (`PUT /remote.php/webdav/<ファイル名>`) でアップロード
2. OCS API (`POST /ocs/v2.php/apps/files_sharing/api/v1/shares`) で公開リンクを作成
3. 同 API の `PUT` でパスワードと有効期限を設定

## インストール

1. `edge://extensions/`（Chrome は `chrome://extensions/`）を開く
2. 「開発者モード」を有効にする
3. 「展開して読み込み」でこのフォルダを選択する

## 使い方

1. 自分の Nextcloud を開き、ログインした状態にする
2. ツールバーの拡張機能アイコンを押す
3. 必要ならパスワードと有効期限を入力し、「アップロードする」を押す
4. ファイルを選ぶとアップロードされ、共有 URL がクリップボードにコピーされる

初めて使うサイトでは確認のためもう一度ボタンを押す必要があります。承認したオリジンは
`chrome.storage.sync` に保存され、次回以降は確認なしで実行されます。登録済みのサイトは
ポップアップ下部に一覧表示され、「削除」で登録を解除できます。

Nextcloud と判定できないページでも、**警告を確認したうえで登録して実行できます**
（ボタンが「警告を承知で登録して続行」に変わります）。判定はあくまで誤操作防止のための
目安で、続行するかどうかはユーザーが決める設計です。

## セキュリティ設計

- **常時注入はしない。** コンテンツスクリプトを全サイトに登録する代わりに、
  `activeTab` + `chrome.scripting.executeScript` で「ユーザーがアイコンを押したタブに、
  その瞬間だけ」注入します。事前のホスト権限宣言も不要です。
- **パスワードを渡す前に対象を確認する。** まず副作用のない検出関数
  (`detectNextcloud`) だけを注入し、Nextcloud だと確認できた場合にのみ
  パスワードを引数として渡します。
- **トップフレームのみ。** `executeScript` の既定の対象はトップフレームなので、
  ページ内の第三者 iframe に入力値が渡ることはありません。
- 未登録のオリジンでは二段階の確認を求めます。承認済みの一覧はポップアップから
  確認・削除できます。

## ストア掲載用アセット

```bash
npm run build:store
```

サーバーが起動したら `http://localhost:8733/build.html` をブラウザで開くだけで、
`store/` に書き出されます（開いた時点で自動生成・自動保存されます）。

両ストアの規定サイズをすべて書き出します（合計 11 点）。

| ファイル | サイズ | 用途 |
| --- | --- | --- |
| `store/logo-300.png` | 300×300 | Edge アドオンのストアロゴ |
| `store/promo-440x280.png` | 440×280 | Chrome ウェブストアの小型プロモタイル |
| `store/screenshot-{1,2,3}-1366x768.png` | 1366×768 | Edge アドオン用スクリーンショット |
| `store/screenshot-{1,2,3}-1280x800.png` | 1280×800 | Chrome ウェブストア用スクリーンショット |
| `store/screenshot-{1,2,3}-640x400.png` | 640×400 | Chrome ウェブストア用（小サイズ枠） |

スクリーンショットの内容は 3 種類です。

1. 入力画面
2. 実行結果と登録済みサイト一覧
3. 未登録サイトでの警告と二段階承認

スクリーンショットは**実物のポップアップをそのまま描画したもの**です。`src/popup.html`
を iframe で動かし、JS が動いた後の DOM を `foreignObject` 経由で画像化しているので、
手描きのモックと違って実装と食い違いません。UI を変えたら再実行してください。

見出しと説明文を変えるときは `store/build/build.html` の `SHOTS` を、
書き出すサイズを変えるときは `SHOT_FORMATS` を編集します。640×400 のような
横幅の狭い規格では、強制改行を無効にして自然改行に任せるようにしてあります。

## 判定と webroot の推定について

対象ページの判定は `<head>` の属性で行います。これは `core/templates/layout.*.php` が
出力するもので、公式の `@nextcloud/auth` も同じ場所からトークンを読んでいます。

- `data-requesttoken` … 全レイアウト（`layout.user.php` / `layout.base.php` /
  `layout.public.php`）にあります
- `data-user` … ログイン済みレイアウトにしかありません。無い場合は公開共有ページや
  ログイン画面の可能性が高いと判断します

**どちらも「警告」であって中断条件ではありません。** 検出に失敗しても、ユーザーが
明示的に承認すれば登録・実行できます。Nextcloud 30 以降は `OCS-APIRequest` ヘッダだけで
CSRF チェックを通過できるため、トークンが取れないページでも成功する場合があるためです
（30 未満では 401 になり、その旨をエラーメッセージで案内します）。

webroot（サブディレクトリ設置）は `<head>` からは取れないため（`data-webroot` 属性は
存在しません）、同一オリジンの `script[src]` / `link[href]` を走査して
`{webroot}/dist/`・`/core/`・`/apps/` の手前を webroot とみなしています。
取れない場合は `/index.php/` の手前、それも無ければ空文字（ルート設置）です。

## CSRF 対策との関係

WebDAV / OCS のどちらも、Cookie 認証のリクエストにはサーバ側で CSRF チェックが入ります
（WebDAV で通らないと `NotAuthenticated: CSRF check not passed.` で 401）。
本拡張はどのバージョンでも通るよう、両方のヘッダを送っています。

| ヘッダ | 効く条件 |
| --- | --- |
| `requesttoken` | 全バージョン。`<head data-requesttoken>` から実行直前に読み直す |
| `OCS-APIRequest: true` | Nextcloud 30 以降。`passesCSRFCheck()` がこのヘッダだけで通す |

`OCS-APIRequest` は CORS のセーフリスト外のヘッダで、クロスオリジンからは付けられないため、
それ自体が CSRF 防御として機能するという設計です。NC 30 未満では効かないので、
トークンの送信も併用しています。

## プライバシーポリシー

最終更新日: 2026年8月18日

### 概要

本拡張機能（Nextcloud-Quick-Share、以下「本拡張」）は、**利用者の個人情報を収集・送信・共有しません**。  
開発者はいかなるデータも受け取りません。  
本拡張が通信する相手は、利用者自身が承認したサーバーのみです。

解析ツール、広告、トラッキング、クラッシュレポート、外部CDNの類は一切使用しておらず、外部のリソースを読み込むこともありません。

### 取り扱うデータ

本拡張がブラウザ内に保存するのは次の2つだけです。  
いずれも利用者の端末（およびブラウザの同期機能）の中にとどまり、外部へ送信されることはありません。

| 領域 | キー | データ内容 | 目的 | 消えるタイミング |
| --- | --- | --- | --- | --- |
| `storage.sync` | `knownOrigins` | 承認済みオリジンの配列 | 利用者が意図しないサイトへ認証情報を送らないための許可リスト | アンインストール時（他デバイスにも伝播） |
| `storage.session` | `lastResult` | 直近の実行結果（共有URLを含む） | ポップアップが閉じた後に結果を表示するため | 次にポップアップを開いた時 / ブラウザ終了時 |

### 保存しないもの

- **共有リンクのパスワードは保存しません。**  
実行のたびに入力され、対象のサーバーへ送信された後は破棄されます。
- 閲覧履歴、ページの内容、フォームの入力内容、Cookie、認証情報を収集・記録しません。
- アップロードしたファイルの内容を、利用者のサイト以外へ送信することはありません。

### データの送信先

ファイルの内容、ファイル名、共有リンクのパスワード、有効期限は、**利用者が承認したサーバーに対してのみ**送信されます。  
送信は利用者がボタンを押した操作を起点とする場合に限られ、認証には当該サイトに既にログインしているセッションを利用します。

### 権限を要求する理由

| 権限 | 用途 |
| --- | --- |
| `activeTab` | 利用者がツールバーのアイコンを押した瞬間に、そのタブに対してのみ処理を実行するため。常時アクセスできる権限は要求していません |
| `scripting` | 上記のタブへ、アップロード処理を一時的に注入するため |
| `storage` | 承認済みサイトオリジンを保存するため |

本拡張は特定サイトへの常時アクセス権（`host_permissions`）を宣言しておらず、バックグラウンドで動作し続けることもありません。

### 第三者提供

一切ありません。  
本拡張はデータを収集しないため、販売・譲渡・開示の対象となるデータが存在しません。

### データの削除方法

- 承認済みサイト: ポップアップ下部の一覧から「削除」を押してください。
- すべてのデータ: 拡張機能をアンインストールしてください。  
保存領域ごと削除され、同期していた内容も他の端末から削除されます。

## 制限事項

- アップロード先はユーザーのルートフォルダ固定です。
- 判定はあくまでUX上のガードです。任意のサイトが `data-requesttoken` を名乗れるため、
  セキュリティ上の保護はオリジン許可リストが担っています。
- 同名ファイルがある場合は `If-None-Match: *` により上書きを避け、`名前-1.ext` の
  ように連番を付けて保存します。
- 大きなファイルはメモリ上に読み込むため、チャンクアップロードには未対応です。
